# Giving useful feedback

This is a feedback-only release. Please open an issue rather than a pull request; code contributions are not accepted (see [LICENSING.md](LICENSING.md)).

A useful report includes the affected file/function, the assumption that fails, an input or event sequence reproducing it, expected behavior, and observed behavior. Please distinguish a code defect from an unimplemented later-phase feature, and check [docs/STATUS.md](docs/STATUS.md) for limitations that are already recorded.

Run reproductions only in a disposable local environment with synthetic data. Do not attach real credentials, account details, private operator records, or identifying logs. This project does not request live venue experiments or real-money tests.

Feedback is reviewed, not automatically accepted, and no public issue can authorize trading or deployment.
